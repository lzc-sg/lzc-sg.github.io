# Zhichao Liao's Homepage

Live site: https://lzc-sg.github.io/

This is a static HTML/CSS site. The main page is `index.html`, and its styles are in `jemdoc.css`. Images are kept in `pic/` and `pub_pic/`.

## Local preview

From the repository root, run:

```sh
python3 -m http.server 8000
```

Then open http://localhost:8000/ in a browser. The visitor counter loads from Statcounter and needs an internet connection.
